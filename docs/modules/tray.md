# 关闭行为与系统托盘

点击窗口关闭按钮时，Koid 按设置决定：**隐藏到系统托盘**、**直接退出**，还是**每次询问**。

## 默认：每次询问

首次关闭时（未配置），Koid 弹出询问框：

- **隐藏到托盘**：以后关闭都隐藏（记住选择）
- **退出**：以后关闭都退出（记住选择）
- **下次再问**：保持「每次询问」，本次先隐藏到托盘，下次关闭继续问

明确选择「隐藏到托盘 / 退出」后会写入设置，之后不再询问。

## 设置

**设置 → 通用 → 关闭行为**，三选一：

| 选项 | 行为 |
| --- | --- |
| 隐藏到系统托盘 | 点关闭 → 窗口隐藏，应用驻留托盘 |
| 直接退出 | 点关闭 → 立即退出 |
| 每次询问 | 每次点关闭都弹出询问框 |

## 系统托盘

应用隐藏到托盘后，托盘图标提供：

- **左键单击**：显示主窗口
- **菜单**：显示 Koid / 退出

托盘在 Windows / macOS / Linux 均可用。
