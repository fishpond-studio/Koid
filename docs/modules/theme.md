# 主题系统

- 6 套预设主题色：`indigo` / `emerald` / `rose` / `amber` / `violet` / `sky`
- 自定义 HEX 实时预览（自动转 HSL，亮度高时前景自适应深色）
- 明暗模式：Light / Dark / System（跟随系统）
- UI 密度：Compact / Default / Comfortable（缩放根字号联动全局）
- 代码字体：JetBrains Mono / Fira Code / Cascadia Code / SF Mono

全部通过 CSS Variables 注入（`src/styles/globals.css`），切换零闪烁。
