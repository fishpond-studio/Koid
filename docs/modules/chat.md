# 对话页

对话页是 Koid 的主界面。头部右侧有一排**常驻控件**——不需要先发送消息，
开启新对话之前就可以直接设置。

## 头部控件

| 控件 | 说明 |
| --- | --- |
| 📄 System Prompt | 编辑当前会话的 System Prompt；无会话时编辑的是「新会话待用值」 |
| 🧠 思考强度 | 五档离散滑块：默认 / 低 / 中 / 高 / 最大 |
| 🎯 上下文占用 | 最近一轮请求 token 数与模型上下文窗口之比，>80% 红色预警 |
| 模型 chip | 跨供应商切换当前会话模型 |

新会话采用延迟创建：首条消息发出时才真正落库。在此之前对 System Prompt 与
思考强度的修改保存在待用值中，创建会话时一并写入数据库，不会丢失。

### System Prompt 层级

1. **会话级**（本页编辑，随会话持久化）
2. **全局默认**（设置 → 提示词 → 默认 System Prompt）

留空保存即回退到上一层级的全局默认。

## 思考强度

五档滑块复刻 Claude Code 的 Effort 卡片（squircle 卡片 + 刻度停靠），
拉到「最大」时触发 WebGL 能量流：火焰模拟 + 双向高斯泛光的四 pass 渲染管线。
配色运行时读取当前主题的 `--primary` 变量派生三档色（深色基底 / 主色 / 白热核心），
**切换主题色瞬间跟随**。

各档位到具体协议参数的映射：

| 档位 | OpenAI 兼容（`reasoning_effort`） | Anthropic（`thinking.budget_tokens`） |
| --- | --- | --- |
| 默认 | 不下发参数 | 不下发参数 |
| 低 | `low` | 4,096 |
| 中 | `medium` | 10,240 |
| 高 | `high` | 20,480 |
| 最大 | `xhigh` | 32,768 |

- 「默认」= 不发送任何思考参数，走模型自身默认行为
- `xhigh` 仅部分新模型（如 Codex-Max 系列）支持；模型报错时降一档即可
- Anthropic 思考模式下按 API 约束自动抬高 `max_tokens`（必须大于预算）并移除
  `temperature`
- 思考过程在消息气泡内以折叠块展示；流式期间显示已思考秒数

系统开启「减少动态效果」（prefers-reduced-motion）时：能量流只渲染静态单帧，
WebGL 不可用时自动降级为 CSS 流光兜底。

## 上下文占用

占用 ≈ 最近一轮 assistant 回复的 `total_tokens` ÷ 模型上下文窗口，
与 auto-compact 的触发口径一致。

- 无会话时回退显示「最近使用模型」的窗口大小
- 占用条 >80% 变红，提示可以执行 `/compact` 压缩上下文
