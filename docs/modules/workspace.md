# 工作区（Vibe Coding）

**工作区是开始 Vibe Coding 的第一步。** 它既是一个会话分组，也可以绑定一个本地项目目录——
绑定后，模型才能读取、搜索项目文件并自主编码。

## 门禁：先选工作区，才能开始

当**当前工作区未绑定项目路径**时，对话页进入门禁状态：

- 欢迎页显示「选择一个工作区开始 Vibe Coding」+ 工作区 chip
- 输入框只读，占位符提示「选择工作区后开始…」，点击/聚焦会弹出工作区选择器
- 发送按钮禁用

> 对齐业界做法：没有项目目录就没有可探索的代码，模型无从下手。

## 选择器（WorkspacePicker）

对话页的工作区 chip 弹出菜单：

- **切换工作区**：列出全部工作区，当前项打勾，显示路径（若已绑定）
- **选择目录并新建工作区**：弹出原生目录对话框，选中后**以目录名命名**创建工作区并绑定
  该路径（同一路径幂等复用，不产生重复工作区）
- **为当前工作区绑定项目路径**：当前工作区未绑定路径时提供

**没有可用（已绑定路径）的工作区时**，点击选择器直接进入目录选择，不弹空菜单。

采纳目录失败（如路径无效）会弹出错误对话框，可「重新选择」重试。

## 文件访问

绑定路径后，侧边栏展示 **工作区文件树**，可点击文件把 `@路径` 引用追加进输入框
（发送时读取内容注入）。

模型通过 Agent 工具自主探索并修改项目：

| 工具 | 说明 |
| --- | --- |
| `list_dir` | 列出指定目录的直接条目 |
| `read_file` | 读取文件内容（≤1MB），支持行范围 |
| `grep` | 正则全文搜索 |
| `glob` | 模式匹配文件 |
| `write_file` | 创建或覆盖文件（父目录自动创建） |
| `edit_file` | 精确字符串替换（old_string 须唯一匹配） |
| `delete_file` | 删除文件（仅文件，不删目录） |
| `run_command` | 在工作区根目录执行 shell 命令（构建/测试/装依赖/git） |

路径经过净化：拒绝绝对路径与 `..` 穿越，限制在工作区根目录内；跳过隐藏文件与
`node_modules` / `.git` / `target` 等大目录。写操作有 10MB 上限，编辑要求 old_string
唯一匹配（对齐 Aider/opencode 的安全编辑模式）。写操作完成后自动刷新文件树。

## 冷启动恢复

启动时若当前工作区未绑定路径，自动切换到「最近会话所属工作区」（其次取最早绑定路径的
工作区），尽量让你一打开就能直接开始。
