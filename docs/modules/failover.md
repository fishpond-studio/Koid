# 模型故障转移

主供应商失败时自动切换到备用供应商。

- **策略**：顺序降级 / 轮询 / 随机
- **触发**：超时（含连接失败 NETWORK）/ 5xx / 空响应 / 内容过滤
- **退避**：`min(base × multiplier^attempt, maxBackoff)`，base = 0.5s
- **日志**：每次转移写入 `failover_logs`
- **通知**：前端 Toast「已自动切换至 {provider}」

## 规则

- 候选 = 已启用、非当前、且至少有 1 个启用模型的供应商
- 流式已输出内容后不再转移（避免重复文本）
- `401/403` 等凭证错误永不转移
