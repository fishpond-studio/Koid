# 会话管理

Koid 的会话按 **Workspace → Session** 两层组织：先选工作区（绑定本地项目目录），再在
其中开启会话。

## 层级

```
Workspace（工作区：分组 + 可选绑定本地项目路径）
  └─ Session（会话：与某个工作区绑定）
       └─ Message（消息：流式落库，即时持久化）
```

> Folder 层级（session 的 `folder_id`）为数据库预留，尚未接入 UI（Phase 2 计划）。

## 新建 / 打开

- **新建会话**：输入区发首条消息时才真正创建（延迟创建，避免产生空会话），并自动归入
  当前工作区。
- **最近恢复**：冷启动自动打开最近会话，并同步其所属工作区作为当前工作区。
- **切换工作区**：点击工作区 chip（对话页底部或欢迎页），选择后会清空不属于该工作区的
  当前会话，落到该工作区的新会话。

## 标题

会话标题在首条消息后自动生成；可手动重命名（会话列表右键 / 详情操作）。

## 归档与删除

- **归档**：隐藏到侧边栏「已归档」区，可随时还原；归档非破坏性。
- **删除**：级联删除会话及其全部消息，不可恢复。

## 消息操作

用户消息悬停显示两个操作（§对话页）：

- **撤回**：删除该消息及其之后的全部内容（含 assistant 回复），用于「这句不说
  了，重新来」。
- **编辑并重发**：截断该消息及其后内容，原文回到输入框并自动重发——@文件引用
  展开、自动压缩等发送流程照常生效。

## 分支

从任意消息处 **分支（Branch）**：复制截止该消息的上下文到新会话，用于"试另一条路"。
分支会话同时继承源会话的工作区、System Prompt 与思考强度。

## 搜索

侧边栏全局搜索（300ms 防抖）：匹配会话标题与消息内容，命中消息高亮摘要，点击跳转到
对应会话并滚动定位。

## 持久化

消息即时写入 SQLite（`append_message`），无额外自动保存节流；会话列表按
`pinned / updatedAt` 排序。
